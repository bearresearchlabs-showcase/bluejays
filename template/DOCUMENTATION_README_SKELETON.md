# DOCUMENTATION/README.md Skeleton — Canonical Structure

Every `source/db-N/app/DOCUMENTATION/README.md` and `source/db-N/docs/README.md` must follow this structure. Use for comparison and validation.

---

## Required Structure

```markdown
---
title: {Database Name} — Documentation
description: Installation guide, specifications, schema, data dictionary.
database: db-{N}
---

# {Database Name} — Documentation

**Database:** db-{N}  
**Content:** Installation guide, specifications, schema, data dictionary.

---

## Installation Guide

### Step 1: Prerequisites

{description}

---

### Step 2: Create Database

{description}

```bash
createdb -U postgres db_{N}
```

---

### Step 3: Load Schema

{description}

```bash
psql -U postgres -d db_{N} -f schema.sql
```

---

### Step 4: Load Data (Optional)

{description}

```bash
psql -U postgres -d db_{N} -f data.sql
```

---

## Specifications

- **PostgreSQL:** {version}
- **Disk:** {disk_space_mb} MB minimum
- **Memory:** {memory_mb} MB minimum
- **Platforms:** {platforms}

{notes}

---

## Schema Overview

**Total tables:** {N}

- `{table_name}` — {description or "(see data dictionary)"}
- ...

---

## Data Dictionary

### `{table_name}`

- `{column_name}` {data_type} {constraints}
- ...

### `{table_name}`

- ...

---

*Generated by documentation workflow. MDX-compatible markdown.*
```

---

## Section Checklist

| Section | Required | Source |
|---------|----------|--------|
| YAML frontmatter (`---` ... `---`) | Yes | config.frontmatter / database |
| `title:` | Yes | database.name |
| `description:` | Yes | config |
| `database:` | Yes | database.id |
| H1 `# {title}` | Yes | same as frontmatter title |
| `**Database:**` | Yes | database.id |
| `**Content:**` | Yes | description |
| `## Installation Guide` | Yes | config.installation_guide |
| `### Step 1:` through `### Step 4:` | Yes | config.installation_guide.steps |
| `## Specifications` | Yes | config.specifications |
| `## Schema Overview` | Yes | deliverable.schema |
| `**Total tables:**` | Yes | deliverable.schema.total_tables |
| Table list `- \`name\` —` | Yes | deliverable.schema.tables |
| `## Data Dictionary` | Yes | deliverable.schema.tables |
| `### \`table_name\`` per table | Yes | deliverable.schema.tables[].name |
| Column list per table | Yes | deliverable.schema.tables[].columns |

---

## Validation

- No ` ```sql ` blocks (README excludes query docs; queries live in QUERIES/)
- Single source of truth: config + deliverable JSON
- MDX-compatible (frontmatter, CommonMark body)
